# 幕山 Moshine 品牌命名与文案体系

## 品牌基础信息

| 项 | 内容 |
| --- | --- |
| 中文主品牌名 | 幕山 |
| 英文主品牌名 | Moshine |
| 域名 | mosliy.com（主站）/ app.mosliy.com（控制台） |
| 品牌定位 | 极致黑白极简 · 高端创作工业感（Linear / Notion 路线） |
| 核心隐喻 | 每一帧画面都是一座值得攀登的山，每一部片子都是一座山岭 |

### 字源

- 中文「幕」取银幕/分幕之意，「山」取稳定·专业·高度·可攀登。
- 英文 Moshine = Mosliy 首 Mo + Shine（光，胶片感光），谐音 Machine 暗示创作机器。

## 品牌语气（Brand Voice）

- 走「克制、专业、有野心的创作攀登者」路线，不极客、不堆砌术语、不喊"最强/顶级"。
- 按钮文案用行动动词（"立即投拍"、"继续上一个项目"、"邀请朋友开拍"），不用技术术语。
- 空态用电影/登山场景式比喻：
  - 不是"暂无数据"，而是"剧本还未落笔，先从一个创意开始吧 🎬"
  - 不是"暂无项目"，而是"山脚已就位，向上开拍吧"
- 术语体系：开拍 / 剧本 / 成片 / 舞台 / 工作室 / 分镜 / 投拍 / 首映 / 攀登。
